# 一次点完：四处写操作

这四处是**唯一**需要你亲手点的东西 —— 它们的成功路径都需要真实账号动作，我无法代替。

点之前先清日志：

```
adb -s 127.0.0.1:16384 logcat -c
```

四处点完，把结果（成功/报错文本）告诉我，我按下面"我查什么"逐条对日志。

---

## 1. 收藏世界（约 30 秒）

**点**：首页 → 任一房间 → 世界页底部「收藏世界」；再点一次取消。

**应该看到**：按钮状态切换；收藏 → 世界 里出现/消失该世界。

**我查**：`app__vrchat_favorite_add` / `app__vrchat_favorite_delete` 的返回。

**报错时**：把文案发我。可能的可读错误：
`Remote favorite mutation requires an authenticated session.`

---

## 2. 标记通知已读（约 15 秒）

**点**：通知 → 点一条**右侧有蓝点**的。

**应该看到**：蓝点消失，左栏通知红点计数减少。

**我查**：`app__notification_mark_seen_batch` 的返回。

> 如果通知里已经没有未读的，这一项可以跳过 —— 我此前也因为这个原因没能验证成功路径。

---

## 3. 换一个模型（约 30 秒）

**点**：收藏 → 模型 → 任选一个 → 应用；再切回原来那个。

**应该看到**：头像/模型变化；切回后恢复。

**我查**：`app__vrchat_avatar_select` 的返回。

> 这一项**可逆**：再选一次就回去了。选它正是因为它只影响你自己的当前模型。

---

## 4. 退出一个群组（约 20 秒，可选）

**点**：任一你已加入的群组页 → 「退出群组」。

**应该看到**：按钮状态变化、成员数减少。

**我查**：`app__vrchat_group_leave` 的返回。

> **这一项会真的改变你的群组成员关系**，而且可能需要群管理重新邀请才能回去。
> 只在你确实想退的群上做；不想做就跳过，我不会把它算作未完成。
