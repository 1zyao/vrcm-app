# 手机端验收清单

这份清单只说三件事：**点哪里**、**应该看到什么**、**我该查什么**。

每一项都对应一次真实的翻转或修复，所以"应该看到"里写了失败长什么样 —— 只说"应该能显示"的
清单没有用。

前置：`adb -s 127.0.0.1:16384 logcat -c` 先清日志，点完告诉我，我按下面第三列去查。

---

## 1. 好友动态（后端读模型 + 同步）

**点**：首页 → 动态 → 依次切换 全部 / 上线/下线 / 位置变动 / 状态/简介变动 / 模型变动

**应该看到**
- 每个 tab 顶部都是**该类型最新的一条**（不是更旧的）
- 模型变动行有"更换前 / 更换后"两张图
- 位置行显示世界名 + access 标签（好友+ / 群组 / 私密）
- 不同 tab 的顶部时间不同（位置↔状态↔模型各自最新）

**失败长什么样**
- 切 tab 后顶部时间**变旧** → `observeThrough` 语义又错了
- 全部 tab 空、其他 tab 有内容 → 空集合过滤又出问题
- 行里出现 `wrld_xxxx` 裸 id → 世界名没查到

**我查**：`feed page:` 日志的 `firstAt`，以及 `app__feed_rows_query` 的返回顺序

---

## 2. 收藏四页（实体 + 分组 + 详情）

**点**：收藏 → 玩家 / 世界 / 模型 / 群组，各切一个分组

**应该看到**
- 玩家：头像 + 名字 + 状态点
- 世界：封面 + 世界名 + 作者
- 模型：缩略图 + 模型名 + 作者
- 群组：群组图标 + 名字
- 切分组后列表**跟着变**（不是一直显示全部）

**失败长什么样**
- 某个 tab 空但"全部"有计数 → 分组标签没对上（第 33 轮修过一次）
- 一行显示 `avtr_xxx` 裸 id → 详情没 hydrate 到（可能是 VRChat 返回 `???`）

**我查**：`FavoritesBaselineCache` 的条目数、`remoteFavoritesById` 的类型分布

---

## 3. 通知（本地读模型 + 标记已读）

**点**：通知 → 点一条**未读**的（右侧有蓝点的那种）

**应该看到**
- 列表带封面、群组名、`群组通知` / `申请加入` 标签
- 点未读后蓝点消失，红点计数减少

**失败长什么样**
- 显示原始类型名（如 `group.announcement`）→ 文案映射漏了
- 点了没反应 / 蓝点还在 → 标记已读命令失败

**我查**：`app__notification_mark_seen_batch` 的返回，以及有没有 `Batch action requires an authenticated session.`

> 这一项是**写操作**，我只能在无会话时验证守卫，成功路径要靠你这一下。

---

## 4. 世界页（世界详情 + 实例 + 文件分析）

**点**：首页 → 点一个房间卡片（或在动态里点"切换了世界"）

**应该看到**
- 世界名、作者、描述、作者标签
- 实例卡片：编号、access、人数（如 3/32）、群组名
- 底部"创建房间 / 收藏世界"按钮

**失败长什么样**
- 封面灰、名字空 → `WorldData` 解码失败（第 35 轮修过 `namespace` / `pluginUrl`）
- 人数显示 0/0 → `full: true` 没传

**我查**：`instance decode` 日志（若还在）、以及 `app__world_get` 的 `full` 参数

---

## 5. 资料页（用户 + 群组 + 收藏 + 屏蔽）

**点**：收藏 → 玩家 → 点任意好友；然后**往下滑**

**应该看到**
- 顶部 banner、名字、状态、语言旗、简介
- 下方：创建的模型 / 收藏的世界 / 群组 / 代表群组
- 右上角菜单里的 JSON 按钮能打开**原始 JSON**

**失败长什么样**
- 下方全空 → profile 命令或 groups 命令失败
- JSON 弹窗空白 → `_userJson` 又没赋值（第 26 轮修过一次）
- 头像全灰 → 图片传输退化（这会同时影响所有页面）

**我查**：`app__vrchat_user_get` / `user_profile_get` / `group_user_groups_get` 的返回

---

## 6. 数据同步（设置页）

**点**：右上角头像 → 设置 → 隐私与数据 → 数据同步；先看，再点「立即同步」

**应该看到**
- 同步状态：**已连接**
- 服务器：`100.70.120.64:5432 / vrcx0`
- 最近一次同步：一个**近几分钟内**的时间（不是 20:46 那个冻结值）
- 点「立即同步」后该时间**往后跳**

**失败长什么样**
- 显示"未配置" → 库里 `config:vrcx_remotesync.*` 没了
- 时间一直不变 → **同步循环没跑**（第 39 轮那个 bug 复发）
- 显示错误文本 → 连不上共享库（Tailscale 断了？）

**我查**：库里的 `_sync_meta.lastCycleAt` 与 UI 显示的对比

---

## 7. 搜索（世界 / 用户 / 群组）

**点**：搜索 → 世界 → 输入 `calm`

**应该看到**：世界列表（Kyrravik / Cozy Calm 之类）

**失败长什么样**
- 一直转圈 → 命令超时
- 一条都没有 → 参数形状不对（注意：`releaseStatus=all` 会 403，代码里已避开）

**说明**：这台模拟器上 `adb input text` 敲不进输入框，所以**这一项我从来没能自动验证过**，需要你手动打一次。

---

## 8. 群组加入/退出

**点**：找一个**你已加入的**群组 → 退出；再找一个**公开群组** → 加入

**应该看到**：按钮状态切换，成员数变化

**失败长什么样**
- 报错文本 → 命令失败，把文本发我
- 点了没反应 → 按钮回调没接上

> 这也是**写操作**，且会真的改变你的群组成员关系。请只在你确实想改的群组上试。

## 我已知但**没有**验证过的（诚实清单）

| 项 | 为什么没验证 |
|---|---|
| 通知标记已读的成功路径 | 需点击未读，会改你真实通知状态 |
| 收藏增删的成功路径 | 需真的收藏再取消 |
| 群组加退的成功路径 | 会改你真实的群组成员关系 |
| 搜索结果的渲染 | 模拟器无法向输入框输入文字 |
| 玩家屏蔽的非空映射 | 该账号库中没有屏蔽记录 |
| 新同步事件的流入 | 远端库自 20:46 后没有新事件 |

## 我不会去做的

- 用你的账号封禁 / 解除好友 / 删除世界或模型 / 踢人
- 为了让"能拉到新事件"成立而在远端共享库里造数据

如果你希望验证其中任何一项，请明确告诉我，我会说明风险后等你点。
